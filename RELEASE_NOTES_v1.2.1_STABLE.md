# Кинотека v1.2.1 Stable — релиз на базе HF60

Дата подготовки: 24 октября 2026 года.

## Состав релиза

- Полностью подтверждённая пользователем версия HF60: центрированный текст сортировки и контекстная подсветка выбранных фильтров.
- 13 сортировок, восстановление выбора после запуска, исправленный сброс, сортировка по статусу.
- Сохранение настоящей даты для вновь добавляемых записей. Для исторических записей отсутствующая дата не выдумывается.
- Карточки с названиями по центру, таблица, локальный поиск и импорт Letterboxd.
- Режим окна Windows 11 HF51: зазор 2 физических пикселя снизу для автоскрываемой панели задач.
- TMDB-поиск полностью удалён; старые идентификаторы используются только локально для совместимости импорта.

## Сборка и распространение

Этот релиз обновляет только версию и релизные сценарии, НЕ изменяя принятый HF60 UI и логику.

Запускать `MAKE-FINAL-RELEASE-v1.2.1.cmd` только в отдельной подготовленной копии исходников с пустыми `data/kinoteka.sqlite3` и `seed-data/kinoteka.sqlite3`. В свежем Git-клоне рабочую пустую базу можно скопировать из seed только при отсутствии `data/kinoteka.sqlite3`. Нельзя очищать или заменять существующую пользовательскую базу ради сборки.
Сценарий использует существующие `node_modules` и Cargo-кеш; сеть принудительно отключена.

Результаты в `Artifacts/Kinoteka_v1.2.1_Stable`:

- `Kinoteka_Standalone_v1.2.1_Stable_Portable.zip` — готовый EXE, ДВЕ пустые канонические базы SQLite и четыре сопроводительных документа, без личных данных.
- `Kinoteka_Standalone_v1.2.1_Stable_Source.zip` — проверяемые полные исходники и тесты, без `node_modules`, `target`, пользовательских баз и постеров.
- `SHA256SUMS.txt` — SHA-256 архивов.
- `RELEASE-METADATA.json` — номер версии, дата, SHA-256 архивов и EXE.

В ходе сборки повторно распаковываются и проверяются оба ZIP.
Сценарий откажется перезаписывать существующие релизные архивы и portable-базу.

## Уточнение упаковки после публикации

Опубликованные файлы тега `v1.2.1` остаются неизменными: Portable содержит три файла, Source — прежнюю структуру с legacy-инструментами в корне. Новые сборки из текущей ветки используют `packaging_revision=2`: в Portable добавлены `LICENSE`, `THIRD_PARTY_NOTICES.md`, `GITHUB_PRIVACY_RU.md`, `README-PORTABLE.txt`; эти документы включаются и в Source. Хеши новой упаковки будут другими; старые метаданные к ней неприменимы. Повторная сборка не заменяет файлы опубликованного релиза автоматически.
