# Кинотека v1.2 Stable — HF58

- «Сбросить» синхронизирует пользовательский список сортировки с фактическим значением А → Я. Внешний вид кнопки не меняется.
- «По статусу» группирует: Избранное → Понравилось → Нормально → Не понравилось → Смотрю → Запланировано; внутри группы по названию.
- Убраны «Случайный порядок» и кнопка перемешивания. Старое предпочтение random безопасно мигрирует на А → Я; legacy значение всё ещё допускается валидатором уже созданной базы, чтобы не вызвать ложное восстановление/сброс SQLite.
- `addedAt` — необязательная дата в UTC ISO-8601 в JSON-состоянии. Новые записи и новые импортированные записи получают фактическое время добавления. Сохранение оценки, избранного и перенос в корзину не меняют дату.
- Исторические записи без `addedAt` сохраняют неизвестную дату, их настоящая дата НЕ выдумывается; при сортировке они идут в прежнем порядке, а новые упорядочиваются по реальным датам. Повторный импорт сохраняет дату совпадающих записей.
- SQL-таблицы, схема SQLite, постеры и личная коллекция не модифицируются установщиком патча; изменения JSON применяются только при реальном сохранении записей в приложении.
