# Кинотека v1.2 Stable — Hotfix 57: SQLite UI sort validation

Исправлена ошибка «Некорректные настройки интерфейса» при выборе расширенных сортировок и последующем сохранении изменений в SQLite. Rust-бэкенд до HF57 разрешал только game-asc и game-desc, тогда как в меню доступны 14 вариантов с HF52. Теперь единый Rust-валидатор принимает все 14 точных значений. Аналогичные проверки в инструментах аудита SQLite согласованы с ним.

Добавлены Rust unit-тесты проверки UI и автоматическая проверка совпадения 14 значений в HTML, Rust и скриптах аудита. Не изменяется структура SQLite, пользовательские данные, картинки, настройки окна, CSS, логика сортировки или кнопка сброса.

Устанавливать поверх HF56, закрыв Кинотеку. При установке проверяются SHA-256 каждого изменяемого файла, создаются резервные копии исходников/EXE, выполняется npm run verify и автономная сборка Tauri. Удалять базу, повторно импортировать Letterboxd и устанавливать npm ci не нужно.
