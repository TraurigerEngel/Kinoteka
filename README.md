# Кинотека (Kinoteka) 🎬

**Актуальная стабильная версия — [v1.2.1 Stable (HF60)](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.2.1).**

Windows 11 x64 · Portable · Tauri 2 / Rust / SQLite · автономная личная медиатека.

[**Скачать v1.2.1**](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.2.1) · [Изменения v1.2.1](RELEASE_NOTES_v1.2.1_STABLE.md) · [История изменений](CHANGELOG.md) · [Приватность](GITHUB_PRIVACY_RU.md)

## Возможности

- Своя библиотека фильмов, сериалов и анимации; карточки и таблица, локальные постеры, категории, оценки 1–10, избранное и корзина.
- Поиск и **13 способов сортировки**. В HF60 надпись выбранной сортировки центрирована; нестандартный порядок подсвечен акцентом, сброс возвращает нейтральное оформление.
- Сохранение выбранной сортировки и фильтров между запусками; реальные даты для новых записей, без выдумывания отсутствующих исторических дат.
- Импорт Letterboxd из ZIP/CSV с предварительной проверкой неоднозначных совпадений.
- Автономное хранение в SQLite; поиск TMDB удалён, старые ID используются только для локальной совместимости импорта.
- Фиксированная геометрия Windows 11; сохранён доступ к нижнему краю для автоскрываемой панели задач.

## Установка (Windows 11 x64)

1. Откройте [релиз v1.2.1 Stable](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.2.1).
2. Скачайте `Kinoteka_Standalone_v1.2.1_Stable_Portable.zip` и распакуйте **в новую папку**.
3. Запустите `Kinoteka.exe`. Для работы требуется Microsoft WebView2 Runtime (обычно есть в Windows 11).
4. **Не заменяйте** файлами пустых баз SQLite собственную коллекцию. Перед переносом пользовательских данных делайте резервную копию.

В Portable включены две одинаковые чистые базы (`data/kinoteka.sqlite3` и `seed-data/kinoteka.sqlite3`) без личных записей. Ваши реальные фильмы и постеры остаются только на вашем устройстве.

## Исходники и проверка

Выпуск включает **оригинальные, неизменённые** `Portable ZIP` и `Source ZIP`, `SHA256SUMS.txt` и `RELEASE-METADATA.json`. В Source ZIP находятся исходники, тесты и сборочные сценарии. Файлы лицензий сохранены в репозитории.

Для проверки исходников нужны Node.js 22.13+, npm 10+, а для Windows-сборки также Rust 1.90+ / MSVC. Для нового Git-клона сначала скопируйте чистую `seed-data/kinoteka.sqlite3` в `data/kinoteka.sqlite3` (если пользовательская база ещё не создана). На подготовленном проекте:

```powershell
npm run verify
```

В тестах проверены HF51–HF60, включая отдельный тест выпуска v1.2.1. Для повторной сборки на Windows используйте `MAKE-FINAL-RELEASE-v1.2.1.cmd` в отдельной подготовленной копии исходников с пустыми базами и сохранёнными зависимостями/кешем Rust. Сборка из каталога с личной коллекцией намеренно отклоняется; очищать такую базу нельзя. Проверка Node не заменяет тест запуска EXE на Windows.

Новая упаковка из текущей ветки (`packaging_revision=2`) добавляет в Portable и Source лицензии, документ приватности и `README-PORTABLE.txt`. Опубликованные ZIP v1.2.1 не изменены и имеют прежний состав. В старом Source `.gitignore` не исключает рабочую SQLite и постеры: для дальнейшей разработки используйте текущий Git-клон; не публикуйте старую распакованную рабочую копию целиком.

## Приватность и лицензии

- Данные хранятся локально в `data/kinoteka.sqlite3`, а пользовательские постеры — на вашем компьютере. Никогда не публикуйте эти файлы в GitHub.
- В репозитории сохраняется только чистая `seed-data/kinoteka.sqlite3`; локальная рабочая SQLite исключена через `.gitignore`.
- Авторский код — [MIT](LICENSE); лицензии сторонних иконок/шрифта Inter — [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Структура репозитория

- `app/` и `src-tauri/` — интерфейс и Rust/Tauri, без изменений в уборке структуры.
- `scripts/` — актуальные автоматические проверки (включая HF60).
- `docs/hotfixes/` — заметки HF53–HF60; `docs/releases/` — история выпусков; `docs/archive/` — оригинальный журнал.
- `tools/legacy/` — исторические инструменты сборки/миграции. Для текущей версии используйте **`MAKE-FINAL-RELEASE-v1.2.1.cmd` из корня**.

Стабильные опубликованные архивы v1.2.0 и v1.2.1 неизменны; полная история доступна в [GitHub Releases](https://github.com/TraurigerEngel/Kinoteka/releases).
