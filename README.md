# Кинотека (Kinoteka) 🎬

**Актуальная тестовая версия — v1.2.0-preview.1 (Preview 1, Hotfix 43).**  
**Последняя стабильная версия — v1.1.0 Stable.**  
Windows 11 x64 · Portable · Tauri 2 / Rust / SQLite

Kinoteka — автономное приложение для ведения личной коллекции фильмов, сериалов и анимации. Вся библиотека хранится **локально**, без аккаунта, обязательного подключения к интернету и облачной синхронизации.

[**Скачать v1.2 Preview 1**](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.2.0-preview.1) · [**Проверенная v1.1 Stable**](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.1.0) · [История изменений](CHANGELOG.md) · [Приватность](GITHUB_PRIVACY_RU.md)

## Основные возможности

- Фильмы, сериалы и анимация в одной библиотеке; поиск, сортировка, категории, таблица и карточки.
- Оценки **1–10**, статусы «Смотрю» и «Запланировано», избранное, корзина с восстановлением.
- Локальные постеры: ручное изображение, вставка из буфера и поиск подходящих материалов Wikimedia Commons по инициативе пользователя. Авторство и условия лицензий изображений зависят от источника.
- Режим «Импорт и каталог»: **ZIP/CSV-экспорт Letterboxd**, предварительный просмотр изменений и ручная проверка неоднозначных совпадений перед сохранением.
- Ручной **поиск TMDB** по названию с пользовательским API-токеном. Токен используется в памяти и не сохраняется в SQLite.
- SQLite и локальное резервное копирование перед подтверждённым импортом.
- Тёмное оформление *Cinema Mono*, локально размещённый Inter, интерфейс в стиле Windows 11.

### Что нового в Preview 1

Импорт Letterboxd (включая watched, ratings, diary, reviews, watchlist и списки), сохранение исходных метаданных, предварительное сравнение найденных и существующих записей, защита от автоматического ошибочного объединения разноязычных/похожих фильмов. В **Hotfix 42–43** упрощён экран ручной проверки, сохранена позиция списка при принятии решения, а отсутствующий тип в экспорте не отображается как конфликт.

**Текущее ограничение:** вкладка **«Мои списки» временно скрыта** в Hotfix 41–43; данные ранее импортированных списков сохраняются в SQLite. Поиск TMDB требует сети и собственного токена. Preview не является заменой v1.1 Stable по гарантии стабильности.

Подробности: [заметки к v1.2 Preview 1](RELEASE_NOTES_v1.2_PREVIEW_1.md).

## Установка Portable (Windows 11 x64)

1. Откройте [релиз v1.2 Preview 1](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.2.0-preview.1).
2. Скачайте **`Kinoteka_Standalone_v1.2_Preview_1_Portable.zip`**.
3. Распакуйте в **новую отдельную папку**. Внутри находятся `Kinoteka.exe`, `data/kinoteka.sqlite3` и `seed-data/kinoteka.sqlite3`.
4. Запустите `Kinoteka.exe`. Для Windows требуется WebView2 Runtime (обычно установлен в Windows 11).
5. Не заменяйте файлы установленной v1.1: для проверки новой версии используйте отдельную папку. Сохраните собственные резервные копии библиотеки до переноса данных.

**Важно:** в опубликованном Portable обе SQLite-базы **пустые** (0 записей, 0 избранных и 0 элементов корзины). Личные фильмы, постеры и данные Letterboxd не включены в архив. Не подменяйте ими базы действующей коллекции без собственной резервной копии.

## Исходники и тестирование

Выпуск включает оригинальный проверенный на Windows **Source ZIP** и отдельный **Portable ZIP**, `SHA256SUMS.txt` и метаданные релиза. SHA-256 подтверждают точные байты этих файлов.

Для свежего Git-клона нужны Node.js 22.13+, npm 10+, Rust 1.90+ с Windows MSVC и Tauri 2 CLI. Перед проверкой скопируйте пустую seed-базу в `data/kinoteka.sqlite3` (если там нет БД), затем:

```powershell
npm ci
npm run verify
.\BUILD-DEV.cmd
```

Для тестирования достаточно команд Node; сборка Windows EXE требует Rust/MSVC. В ветке GitHub добавлен **синтетический тестовый ZIP**, отсутствующий в исходном Source ZIP, и из набора `npm run verify` исключены две исторические проверки, зависевшие от не входящих в публичную поставку инструментов патчей. Это изменения **только тестовой инфраструктуры**, без изменений приложения или Windows EXE. Полная воспроизводимая проверка выполняется из Git-клона, а оригинальные релизные ZIP сохранены неизменными.
