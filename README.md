# Кинотека (Kinoteka) 🎬

**v1.1.0 Stable — Clean Data Edition** · Windows 11 x64 · Tauri 2 / Rust / SQLite

Автономное приложение для личного каталога **фильмов, сериалов и анимации**. Позволяет вести списки просмотра, отмечать понравившиеся произведения, добавлять избранное и восстанавливать удалённые записи. Данные сохраняются локально.

**[Скачать Portable v1.1.0](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.1.0)** · [Конфиденциальность](GITHUB_PRIVACY_RU.md) · [История изменений](CHANGELOG.md)

## Возможности

- Отдельные категории для фильмов, сериалов и анимации.
- Поиск, сортировка, фильтры и пользовательские оценки.
- Избранное и корзина с восстановлением записей.
- Локальная база **SQLite** и резервное копирование.
- Тёмная тема *Cinema Mono*, собственная строка заголовка и плавный запуск.
- Портативное приложение без установщика для **Windows 11 x64**.

## Установка

1. Откройте [релиз v1.1.0 Stable](https://github.com/TraurigerEngel/Kinoteka/releases/tag/v1.1.0).
2. Скачайте **`Kinoteka_v1.1.0_Clean_Portable.zip`**.
3. Распакуйте архив в отдельную папку и запустите **`Kinoteka.exe`**.
4. Не удаляйте каталог **`data`**: там будет храниться ваша собственная библиотека.

**Проверка Windows:** пользователь подтвердил успешную работу Clean Portable на Windows 11. Оригинальный исполняемый файл не менялся; очищены только две внешние SQLite-базы.

## Конфиденциальность и демо-данные

**Личная библиотека не публикуется.** Для этой редакции создана новая SQLite-база со схемой оригинала, но без пользовательских названий и оценок:

- `seed-data/kinoteka.sqlite3` содержит **0 записей, 0 избранных, 0 элементов корзины**.
- `data/kinoteka.sqlite3` **не отслеживается Git**, а создаётся локально через `INIT-DEMO-DATA.cmd`.
- Резервные копии и изменённые рабочие базы исключены из репозитория.
- Проверки исходников и сборочного процесса отклоняют базы, не совпадающие с чистой демо-копией.

Подробности: [GITHUB_PRIVACY_RU.md](GITHUB_PRIVACY_RU.md).

## Разработка и сборка

Нужны **Node.js 22.13+**, npm 10+, Rust с MSVC и компоненты для сборки Tauri 2 на Windows.

Откройте PowerShell в корне клонированного проекта:

```powershell
.\INIT-DEMO-DATA.cmd
npm ci
npm run verify
npm run build:dev
```

Полная релизная сборка после проверки:

```powershell
.\MAKE-FINAL-RELEASE.cmd
```

Финальная сборка включает проверку JavaScript, SQLite, безопасности демо-данных и исходников Rust. Шрифты в GitHub-исходниках используют установленный в системе Inter или системную альтернативу; готовый EXE не пересобирался.

**Примечание:** принятая реализация запуска — Hotfix 6, без отклонённого Hotfix 7. Короткий чёрный кадр Windows/WebView2 перед появлением интерфейса может сохраняться.
