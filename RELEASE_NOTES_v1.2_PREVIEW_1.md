# Kinoteka v1.2 Preview 1 (Hotfix 43) 🎬

**Предварительный выпуск** автономной Кинотеки для **Windows 11 x64** на Tauri 2 / Rust / SQLite. Ветка версии: `1.2.0-preview.1`. Стабильная `v1.1.0` остаётся доступной отдельно.

## Что нового

- **Импорт Letterboxd ZIP/CSV:** просмотренные фильмы, оценки, дневник, рецензии, отложенное и пользовательские списки (`lists/*.csv`). Удалённые и вспомогательные экспорты намеренно не импортируются.
- **Предпросмотр импорта:** новые записи, точные совпадения, записи из корзины и подозрительные дубликаты. Неоднозначные решения требуют **ручного подтверждения**; существующие оценки, избранное и корзина сохраняются.
- **Уточнение совпадений** по названию, году, типу и при наличии проверенных идентификаторов; без слепого объединения русских и английских названий.
- **Hotfix 42–43:** компактные строки проверки дубликатов, наглядные различия типов, действия над записью без лишней прокрутки и сохранение позиции после решения.
- **Поиск TMDB** по русскому названию (по запросу, с собственным API-токеном, который не сохраняется в базе).
- **Полировка интерфейса:** карточки/таблица, локальный Inter, постеры, статусы, нативное копирование, подсказки, контекстные действия, анимация и адаптация к панели задач Windows.

**Особенность:** вкладка «Мои списки» в интерфейсе временно скрыта после Hotfix 41; ранее импортированные списки **не удаляются**.

## Установка

1. Скачайте **`Kinoteka_Standalone_v1.2_Preview_1_Portable.zip`** ниже.
2. Распакуйте в новую папку (отдельно от v1.1 Stable).
3. Запустите `Kinoteka.exe` на Windows 11 x64.
4. Не заменяйте действующую SQLite без собственной резервной копии.

## Приватность

В Portable ZIP находятся `Kinoteka.exe` и **две чистые SQLite-базы**: 0 фильмов/сериалов/анимации, 0 избранного, 0 корзины. Личная библиотека, локальные постеры, cookies, токены и экспорт Letterboxd не поставляются.

## Файлы выпуска

- `Kinoteka_Standalone_v1.2_Preview_1_Portable.zip` — готовая Windows Portable.
- `Kinoteka_Standalone_v1.2_Preview_1_Source.zip` — исходники, полученные от Windows-сборки.
- `SHA256SUMS.txt` — SHA-256 обоих архивов.
- `RELEASE-METADATA.json` — версия, канал, время сборки и хеш EXE.

## Проверки и ограничения

- ZIP-архивы проходят тест целостности. SHA-256 исходников, Portable и EXE совпадают с предоставленными метаданными.
- Проверена структура обеих SQLite, `PRAGMA integrity_check = ok` и пустое состояние.
- Node.js проверки импортера, карточек и Hotfix 43 пройдены в подготовленной публикационной копии. Для полной проверки GitHub-исходников добавлен отсутствовавший в оригинальном Source ZIP синтетический тестовый набор и исключены две исторические проверки патч-скриптов, которые не входят в релизную поставку.
- Работа основного приложения на Windows была проверена при подготовке Portable. Действие реального импорта пользовательского Letterboxd и живой TMDB-поиск зависят от среды/аккаунтов и могут потребовать дополнительной проверки.
- Это **Preview / Pre-release**, а не новая стабильная версия.
