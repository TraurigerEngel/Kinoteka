КИНОТЕКА STANDALONE v1.2 STABLE (HF49)
====================================

Актуальная стабильная версия для Windows 11 x64 / Tauri 2.

Готовый запуск:
  Распакуйте Portable в новую папку и запустите Kinoteka.exe.
  Не перезаписывайте рабочую data/kinoteka.sqlite3: в дистрибутиве база ПУСТАЯ.

Работа с исходниками:
  1. Установите Node.js 22.13+, npm 10+, Rust/MSVC.
  2. npm ci
  3. npm run verify
  4. BUILD-RELEASE.cmd

В версии v1.2 HF49 исправлена геометрия окна, взаимодействие с автоскрываемой
панелью задач Windows 11, поведение модальных окон. Поиск TMDB удалён (HF44).
Остались локальная коллекция, ручные постеры/Commons и импорт Letterboxd.

При работе с GitHub проверьте README.md, GITHUB_PRIVACY_RU.md,
RELEASE_NOTES_v1.2_STABLE.md. Старые релизы сохранены.

СОБЛЮДАЙТЕ КОНФИДЕНЦИАЛЬНОСТЬ: не коммитьте личную базу, постеры,
пользовательские ZIP/CSV, резервные копии, ключи, логи и токены.
