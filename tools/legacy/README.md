# Исторические инструменты

Эти сценарии сохранены для совместимости с ранними этапами проекта. Запускайте их из проверенной Windows-копии исходников только при необходимости, учитывая их исторические каталоги назначения.

**Для текущей Kinoteka v1.2.1 Stable** используйте сценарии в корне: `BUILD-RELEASE-v1.2.1.cmd` и `MAKE-FINAL-RELEASE-v1.2.1.cmd`. Не запускайте старые сборщики вместо актуальных.

Все `.ps1` в этой папке определяют корень проекта через `../..`; `.cmd` указывают на соседние `.ps1`. При перемещении скриптов не менялись пользовательские данные, Rust, SQLite или интерфейс.
