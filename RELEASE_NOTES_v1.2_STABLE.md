# Кинотека v1.2 Stable — HF49

Дата: 20 октября 2026 г.
Статус: Stable — версия HF49 проверена и принята пользователем.

## Что включено

- Самостоятельная Кинотека для Windows 11 (Tauri 2, локальная SQLite).
- Карточки и таблица, оценки, статусы, избранное, локальные постеры.
- Импорт Letterboxd, сохранение пользовательских данных.
- Поиск только по локальной коллекции: сетевой поиск TMDB удалён.
- Исправления оконных границ HF45–HF49: модальные окна, отсутствие боковых щелей, совместимость с автоскрываемой панелью задач.

## Распространение

`Kinoteka_Standalone_v1.2_Stable_Portable.zip` содержит только три файла: `Kinoteka.exe`, `data/kinoteka.sqlite3`, `seed-data/kinoteka.sqlite3`. Оба SQLite-файла пустые, идентичны и проходят проверку целостности; пользовательские базы, постеры и резервные копии не экспортируются.

## Сборка без повторных загрузок

Запустите `MAKE-FINAL-RELEASE.cmd` в подготовленном проекте с уже установленными `node_modules` и Cargo-кешем. Команды выполняют проверку исходников, offline-сборку, создание ZIP и проверку повторной распаковки. Доступ к сети не нужен при полном кеше зависимостей.

Готовые архивы создаются в `Artifacts/Kinoteka_v1.2_Stable/` и не перезаписываются.
