# Конфиденциальность — Kinoteka v1.2.1 Stable (HF60)

Релиз v1.2.1 подготовлен для **публичного** репозитория. Проверенные Portable и Source ZIP не содержат пользовательской коллекции.

- В Portable: `Kinoteka.exe` и две одинаковые чистые SQLite-базы по 12 288 байт, `PRAGMA integrity_check = ok`.
- `state.payload` содержит `items=[]`, `favorites=[]`, `trash=[]` и `revision=0`; `ui_state` имеет начальные значения, не содержащие личные данные.
- В Source ZIP присутствуют такие же две чистые базы, в Git отслеживается только чистая `seed-data/kinoteka.sqlite3`.
- Рабочая база `data/kinoteka.sqlite3`, дампы, резервные копии и локальные постеры не добавляются в публичный репозиторий.
- Проверены имена файлов и содержимое текстовых файлов Source ZIP на явные ключи, токены, персональные URL и пути пользователя; совпадений не обнаружено. Это не формальная гарантия отсутствия любых конфиденциальных данных.
- Из личной рабочей папки **нельзя** копировать `data/`, `posters/` и пользовательские архивы. Не заменяйте действующую пользовательскую базу чистой базой из Portable.
- Авторский код лицензирован по [MIT](LICENSE); условия сторонних компонентов: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

SHA-256 обоих оригинальных ZIP указаны в файлах выпуска `RELEASE-METADATA.json` и `SHA256SUMS.txt`.
