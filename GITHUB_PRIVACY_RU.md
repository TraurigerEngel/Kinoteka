# Kinoteka v1.2 Preview 1 — конфиденциальность

Публичные архивы созданы с нулевыми SQLite; личная коллекция не включена.

- `data/kinoteka.sqlite3` и `seed-data/kinoteka.sqlite3` в готовом Portable ZIP: **два одинаковых файла по 12 288 байт**, `PRAGMA integrity_check = ok`; в `state.payload` пустые `items`, `favorites`, `trash`, `revision=0`.
- Source ZIP содержит такие же чистые базы. В Git репозитории хранится только пустая `seed-data/kinoteka.sqlite3`; рабочая база из `data/` исключена через `.gitignore`.
- В архивах нет `posters/`, локальных пользовательских резервных копий, экспортов Letterboxd, токенов и секретов.
- При установке нового Preview архив нужно распаковывать **в новую папку**: не перезаписывайте существующую пользовательскую SQLite.
- Изображения и метаданные сторонних источников требуют проверки прав при публичном распространении; в данных ZIP пользовательских постеров нет.

Оригинальные метаданные и контрольные суммы сборки: `RELEASE-METADATA.json`, `SHA256SUMS.txt` среди вложений выпуска.
